# Kosher Butcher Online (איטליז אונליין)

אפליקציית שולחן עבודה וניהול (WPF) המיועדת להזמנת מוצרי בשר ועופות טריים וקפואים ישירות מהסניף המקומי, תוך מתן מענה ניהולי מלא לבעל העסק[cite: 1]. הפרויקט פותח כפרויקט גמר בסמינר "דרכי חנה" (בית יעקב) במסגרת חלופת אפליקציות אסינכרוניות[cite: 1].

---

## 🚀 טכנולוגיות וסביבת פיתוח
* **צד שרת (Server):** C#, WCF (Windows Communication Foundation), .NET Framework[cite: 1].
* **שכבת נתונים (Data Access):** Entity Framework, MS SQL Express[cite: 1].
* **צד לקוח (Client):** WPF (Windows Presentation Foundation) עם XAML ו-C#[cite: 1].
* **סביבת עבודה:** Visual Studio 2022[cite: 1].

---

## 📋 מאפייני המערכת

### 👤 ממשק הלקוח (משתמש)
* **רישום וכניסה:** אפשרות לרישום לקוח חדש (הזנת פרטים אישיים וכתובת) או זיהוי מהיר ללקוח קיים באמצעות מספר טלפון[cite: 1].
* **קטגוריות ומוצרים:** צפייה במוצרים לפי קטגוריות (עוף טרי, בשר קפוא וכו'), כולל חיווי על מצב המלאי ("חסר במלאי")[cite: 1].
* **עגלת קניות:** שימוש ברכיבי `UserControl` מתקדמים להוספה, הפחתה וניהול כמויות במוצרי הבשר[cite: 1].
* **תשלום ומשלוחים:** חישוב מחיר משוער (עקב שקילת המוצרים), בחירת אמצעי תשלום (אשראי, מזומן או צ'ק למשלוחן), וחישוב אוטומטי של דמי משלוח (חינם בקנייה מעל 500 ₪)[cite: 1].
* **אזור אישי:** צפייה בהיסטוריית הזמנות קודמות ועדכון פרטים אישיים[cite: 1].

### 🛠️ ממשק המנהל
* **ניהול הזמנות:** צפייה בטבלת ההזמנות הנכנסות, עדכון סטטוס ההזמנה ל-"נשלח", והורדת ההזמנה מרשימת ההמתנה[cite: 1].
* **ניהול מלאי וקטגוריות:** הוספה, עדכון ומחיקה של מוצרים, קטגוריות, סוגי כשרויות, ערים ולקוחות[cite: 1].
* **ניהול תמונות:** מנגנון העלאת תמונות (מוצרים, קטגוריות וכשרויות) המאחסן את הקבצים בשרת ושולף אותם באמצעות שירותי הרשת (WCF)[cite: 1].
* **אבטחה:** כניסת מנהל מוגנת סיסמא עם אפשרות לשינוי הסיסמא במערכת[cite: 1].

## 🗄️ מבנה מסד הנתונים (Database)
המערכת מבוססת על בסיס נתונים רלציוני הכולל את הטבלאות המרכזיות הבאות:
* **Customers** (לקוחות)[cite: 1]
* **Products** (מוצרים)[cite: 1]
* **Inviting** (הזמנות ראשיות)[cite: 1]
* **Hazmana** (פירוט מוצרים בהזמנה)[cite: 1]
* **Cities** (ערים וימי אספקה)[cite: 1]
* **Kategor** (קטגוריות)[cite: 1]
* **Kosher** (כשרויות)[cite: 1]

---

## ⚙️ ארכיטקטורת התוכנה
הפרויקט בנוי בארכיטקטורה רב-שכבתית:
1. **שכבת הנתונים (Data Layer):** מנוהלת על ידי Entity Framework לשימוש באובייקטים ומחלקות מול מסד הנתונים[cite: 1].
2. **שכבת העסקים (BLL - Business Logic Layer):** המרת ישויות הנתונים למחלקות פשוטות יותר המאפשרות מעבר נתונים חלק בין השרת ללקוח[cite: 1].
3. **שכבת שירותי רשת (WCF Service):** חשיפת חוזים (`IService1`) לביצוע פעולות שליפה, הוספה, עדכון ומחיקה מול השרת[cite: 1].
4. **שכבת התצוגה (Presentation Layer):** אפליקציית WPF המספקת ממשק משתמש גרפי ידידותי ומותאם[cite: 1].
