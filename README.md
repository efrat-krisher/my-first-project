Kosher Butcher Online (איטליז אונליין)אפליקציית שולחן עבודה וניהול (WPF) המיועדת להזמנת מוצרי בשר ועופות טריים וקפואים ישירות מהסניף המקומי, תוך מתן מענה ניהולי מלא לבעל העסק. הפרויקט פותח כפרויקט גמר בסמינר "דרכי חנה" (בית יעקב) במסגרת חלופת אפליקציות אסינכרוניות.   🚀 טכנולוגיות וסביבת פיתוחצד שרת (Server): C#, WCF (Windows Communication Foundation), .NET Framework.   שכבת נתונים (Data Access): Entity Framework, MS SQL Express.   צד לקוח (Client): WPF (Windows Presentation Foundation) עם XAML ו-C#.   סביבת עבודה: Visual Studio 2022.   📋 מאפייני המערכת👤 ממשק הלקוח (משתמש)רישום וכניסה: אפשרות לרישום לקוח חדש (הזנת פרטים אישיים וכתובת) או זיהוי מהיר ללקוח קיים באמצעות מספר טלפון.   קטגוריות ומוצרים: צפייה במוצרים לפי קטגוריות (עוף טרי, בשר קפוא וכו'), כולל חיווי על מצב המלאי ("חסר במלאי").   עגלת קניות: שימוש ברכיבי UserControl מתקדמים להוספה, הפחתה וניהול כמויות במוצרי הבשר.   תשלום ומשלוחים: חישוב מחיר משוער (עקב שקילת המוצרים), בחירת אמצעי תשלום (אשראי, מזומן או צ'ק למשלוחן), וחישוב אוטומטי של דמי משלוח (חינם בקנייה מעל 500 ₪).   אזור אישי: צפייה בהיסטוריית הזמנות קודמות ועדכון פרטים אישיים.   🛠️ ממשק המנהלניהול הזמנות: צפייה בטבלת ההזמנות הנכנסות, עדכון סטטוס ההזמנה ל-"נשלח", והורדת ההזמנה מרשימת ההמתנה.   ניהול מלאי וקטגוריות: הוספה, עדכון ומחיקה של מוצרים, קטגוריות, סוגי כשרויות, ערים ולקוחות.   ניהול תמונות: מנגנון העלאת תמונות (מוצרים, קטגוריות וכשרויות) המאחסן את הקבצים בשרת ושולף אותם באמצעות שירותי הרשת (WCF).   אבטחה: כניסת מנהל מוגנת סיסמא עם אפשרות לשינוי הסיסמא במערכת.   🗄️ מבנה מסד הנתונים (Database)המערכת מבוססת על בסיס נתונים רלציוני הכולל את הטבלאות המרכזיות הבאות:Customers (לקוחות)   Products (מוצרים)   Inviting (הזמנות ראשيות)   Hazmana (פירוט מוצרים בהזמנה)   Cities (ערים וימי אספקה)   Kategor (קטגוריות)   Kosher (כשרויות)   ⚙️ ארכיטקטורת התוכנההפרויקט בנוי בארכיטקטורה רב-שכבתית:שכבת הנתונים (Data Layer): מנוהלת על ידי Entity Framework לשימוש באובייקטים ומחלקות מול מסד הנתונים.   שכבת העסקים (BLL - Business Logic Layer): המרת ישויות הנתונים למחלקות פשוטות יותר המאפשרות מעבר נתונים חלק בין השרת ללקוח.   שכבת שירותי רשת (WCF Service): חשיפת חוזים (IService1) לביצוע פעולות שליפה, הוספה, עדכון ומחיקה מול השרת.   שכבת התצוגה (Presentation Layer): אפליקציית WPF המספקת ממשק משתמש גרפי ידידותי ומותאם.
